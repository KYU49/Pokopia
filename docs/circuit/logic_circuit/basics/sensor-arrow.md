# センサー矢印の仕様

矢印マス自身がセンサー本体です。

## 監視対象

矢印の先端方向1マスを監視します。

| 矢印 | 監視方向 |
|---|---|
| ← | 左 |
| → | 右 |
| ↑ | 上 |
| ↓ | 下 |

## 変化指令の送り先

監視対象に変化があった場合、矢印マスを基準として次の3方向へ変化指令を送ります。

- 矢印の後ろ側1マス
- 矢印の上側1マス
- 矢印の下側1マス

**矢印の先端方向は変化対象に含まれません。**

### 例：→の場合

- 右側を監視
- 左・上・下へ変化指令

### 例：←の場合

- 左側を監視
- 右・上・下へ変化指令

:::tip
「どこを見ているか」と「どこへ信号を送るか」は別です。回路を組むときは、矢印の向きだけでなくセンサー本体の周囲3マスも確認します。
:::
