# 信号の出力条件

ぽこあ回路では、アイテムの「動作中／停止中」と「電源あり／なし」の組み合わせが重要です。

## 電源を必要としないアイテム

| 状態変化 | 信号 |
|---|---|
| 停止中 → 動作中 | あり |
| 動作中 → 停止中 | なし |

## 電源を必要とするアイテム

電源がない間は、動作状態の変更指令を受けても状態を変えられません。

| 変化 | 信号 |
|---|---|
| 電源なし・動作中 → 電源あり・動作中 | あり |
| 電源なし・停止中 → 電源あり・停止中 | なし |
| 電源あり・停止中 → 動作中 | あり |
| 電源あり・動作中 → 停止中 | なし |
| 電源あり → 電源なし | なし |

![電源と動作状態の信号出力条件](/img/Bashii/SignalOutputConditions.jpeg)

:::tip
回路では「停止から動作へ変わった瞬間」だけでなく、「電源なしの動作中から電源ありになった瞬間」にも信号を出せる点が重要です。
:::
