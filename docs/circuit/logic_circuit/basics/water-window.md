# 水・窓による信号伝達

水流や窓の開閉は、ぽこあ回路で信号を伝える代表的な方法です。

![水窓信号出力条件と水流挙動](/img/Bashii/WindowWaterSignalsAndFlow.jpeg)

## 基本的な見方

- 水が届くことで対象が動作する
- 窓の開閉で水路や動作条件を切り替える
- 水流には移動時間がある
- 配置方向によって信号タイミングが変わる場合がある

:::warning
方角依存により、同じ形でも信号出力のタイミングが変わる場合があります。
:::
