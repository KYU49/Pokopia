# セットリセット回路

> **SETで保持し、RESETで解除する。**

| 項目 | 内容 |
|---|---|
| 分類 | 基礎論理回路 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 状態の記憶 |
| 状態保持 | あり |
| リセット | 必要 |

## できること

SET入力を受けた状態を保持し、RESET入力が来るまでその状態を維持します。

## 仕組み

保持対象の状態をSET側で変化させ、RESET側から元の状態へ戻します。

## 作るときのポイント

- SETとRESETを同時入力した場合の挙動を確認する
- 初期状態を決めておく
- リセット経路を必ず用意する

## 応用

- 選択状態の保持
- ロック回路
- 演算結果の保存
