# 少し早いAND回路

> **2つの条件がそろったときだけ出力する。**

| 項目 | 内容 |
|---|---|
| 分類 | 基礎論理回路 |
| 難易度 | ★★☆☆☆ |
| 主な用途 | 複数条件の成立判定 |
| 状態保持 | なし |
| リセット | 不要 |

## できること

2つの入力が両方成立した場合だけ、次の回路へ信号を送ります。条件判定・認証・演算の基礎になる回路です。

## 仕組み

片方だけの入力では最終出力へ届かず、2つの条件がそろったときだけ出力側が動作するように構成します。

## 作るときのポイント

- 片方だけ入力したときに出力されないことを確認する
- 両方の入力順が変わっても正しく判定できるか確認する
- 方角依存がある場合は向きをそろえる

## 応用

- 認証装置
- 加算回路
- 複数条件で動く設備
