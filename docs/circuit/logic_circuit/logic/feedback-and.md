# フィードバック機構を利用したAND回路

> **電源状態と別入力の両方がそろったときだけ出力する。**

| 項目 | 内容 |
|---|---|
| 分類 | 基礎論理回路 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 複合条件判定 |
| 状態保持 | 構成による |
| リセット | 構成による |

## できること

フィードバック機構を条件ゲートとして利用するAND回路です。電源がONのときだけ、別の入力を通す構成にできます。

## 仕組み

フィードバック側が有効な状態で、もう一方の入力が入ったときだけ最終出力へ信号が届くようにします。

- 複数の構成例で動作時間が異なる場合がある
