# フィードバック機構

> **出力を自分自身へ戻し、電源状態を制御する。**

| 項目 | 内容 |
|---|---|
| 分類 | 基礎論理回路 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 電源状態による入力制御 |
| 状態保持 | 構成による |
| リセット | 構成による |

## できること

電源が必要なアイテムの信号出力条件を利用し、出力を回路自身へ戻して状態を変化させます。電源を利用する多くの回路の土台です。

## 仕組み

電源あり・停止中から動作中になったときの出力を利用し、その信号で別の部品を変化させ、さらに元の対象へ作用させます。

## 作るときのポイント

- 電源なしの間は状態変更できない点を利用する
- 動作→停止では信号が出ないことを前提にする
- 戻り信号が意図せず複数回入らないようにする

## 応用

- 電源ON時だけ他入力を通す
- AND回路
- 自己停止機構
