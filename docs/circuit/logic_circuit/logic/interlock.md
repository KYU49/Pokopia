# 相互ロック回路

> **片方が動いている間、もう片方を動かさない。**

| 項目 | 内容 |
|---|---|
| 分類 | 基礎論理回路 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 同時動作の防止 |
| 状態保持 | あり |
| リセット | 必要 |

## できること

2つの系統が同時に動作すると困る場合に、一方の動作中はもう一方を受け付けないようにします。

## 仕組み

それぞれの動作状態を相手側の禁止条件として利用します。

## 作るときのポイント

- 両方を同時に入力した場合の優先順位を確認する
- 解除後に反対側が正常に動作できるか確認する

## 応用

- 切替装置
- 排他的な選択回路
- 安全装置
