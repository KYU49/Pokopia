# 押した回数で花火の演出が変わる装置

> **入力回数に応じて花火の演出を変える。**

| 項目 | 内容 |
|---|---|
| 分類 | 回路を利用した設備 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 回数連動演出 |
| 状態保持 | あり |
| リセット | 必要 |

## できること

ボタンを押した回数を回路で記録し、その値に応じて花火の演出を切り替えます。

## 仕組み

入力回数を保持またはカウントし、対応する出力先だけを動作させます。

## 作るときのポイント

- 最大回数とリセット条件を決める
- 演出中の追加入力を受け付けるか決める
- 誤入力時の状態を確認する

## 応用

- ゲーム演出
- 回数選択装置
- イベント設備
