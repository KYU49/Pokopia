# 色替え滝

> **操作に応じて滝の色や流れ方を切り替える。**

| 項目 | 内容 |
|---|---|
| 分類 | 回路を利用した設備 |
| 難易度 | ★★☆☆☆ |
| 主な用途 | 水流演出 |
| 状態保持 | 構成による |
| リセット | 構成による |

## できること

回路と水流を組み合わせ、操作によって見た目が変わる滝を作ります。

## 仕組み

選択回路や窓の開閉で、流す水路や表示部分を切り替えます。

## 作るときのポイント

- 水路同士が混ざらないようにする
- 切替後に前の色が残らないか確認する
- 観覧方向から配線を隠す

## 応用

- 広場の演出
- 色切替アート
- 選択回路の展示
