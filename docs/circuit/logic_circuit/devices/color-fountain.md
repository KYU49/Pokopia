# 押すたび色が変わるふんすいひろば

> **ボタンを押すたび、噴水の色や表示を切り替える。**

| 項目 | 内容 |
|---|---|
| 分類 | 回路を利用した設備 |
| 難易度 | ★★☆☆☆ |
| 主な用途 | 選択式水流演出 |
| 状態保持 | あり |
| リセット | 構成による |

## できること

1つの操作で噴水の表示状態を順番に切り替える設備です。

## 仕組み

循環セレクタで現在の色を保持し、選択された水路や表示だけを動作させます。

## 作るときのポイント

- 色数と選択段数を一致させる
- 切替時の残留水を確認する
- 初期色を決める

## 応用

- 広場の装飾
- 選択回路の展示
- インタラクティブアート
