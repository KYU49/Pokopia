# 電卓

> **入力・加算・カウント・表示を組み合わせた計算設備。**

| 項目 | 内容 |
|---|---|
| 分類 | 回路を利用した設備 |
| 難易度 | ★★★★★ |
| 主な用途 | 計算・数値表示 |
| 状態保持 | あり |
| リセット | 必要 |

## できること

ボタン入力を回数へ変換し、加算・カウント・表示回路を組み合わせて計算結果を表示します。

## 仕組み

入力回路、指定回数出力、カウントアップ、演算、表示の各機構を段階的に接続します。

## 作るときのポイント

- 入力中と計算中を分ける
- 計算完了後に全体をリセットする
- 表示桁と内部ビットの対応を明記する

## 応用

- 加算器の展示
- 数値入力装置
- カウンタ設備
