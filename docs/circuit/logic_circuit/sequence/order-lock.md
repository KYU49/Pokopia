# 順番入力式ロック回路

> **決められた順番で入力したときだけ解除する。**

| 項目 | 内容 |
|---|---|
| 分類 | 選択・順序制御 |
| 難易度 | ★★★★☆ |
| 主な用途 | 順番認証 |
| 状態保持 | あり |
| リセット | 必要 |

## できること

入力を正しい順番で行った場合だけ、ロック解除や最終出力を行います。

## 仕組み

各入力段階を保持し、現在の段階に対応した入力だけを次へ進めます。誤入力時にリセットする構成と、進行を維持する構成があります。

## 作るときのポイント

- 正解順と誤入力時の挙動を明記する
- 途中から入力し直せるか決める
- リセット方法を見える位置に用意する

## 応用

- 暗証番号装置
- 順番パズル
- イベント進行
