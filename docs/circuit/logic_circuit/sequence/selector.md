# 循環セレクタ

> **入力のたびに選択先を次へ進める。**

| 項目 | 内容 |
|---|---|
| 分類 | 選択・順序制御 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 順次選択 |
| 状態保持 | あり |
| リセット | 構成による |

## できること

入力するたびに選択先が順番に切り替わり、最後まで進むと最初へ戻ります。

## 仕組み

現在の選択状態を保持し、入力ごとに次の状態だけをONにします。

## 作るときのポイント

- 常に1つだけ選択されるか確認する
- 最後から最初へ正しく戻るか確認する
- 初期選択位置を決める

## 応用

- 表示切替
- 行き先選択
- 演出パターン切替
