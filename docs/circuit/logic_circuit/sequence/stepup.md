# ステップアップ回路

> **入力ごとに処理を1段ずつ進める。**

| 項目 | 内容 |
|---|---|
| 分類 | 選択・順序制御 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 工程・段階制御 |
| 状態保持 | あり |
| リセット | 構成による |

## できること

入力を受けるたびに、現在の段階から次の段階へ進みます。

## 仕組み

各段に保持状態を用意し、入力時に現在段を解除して次段を有効にします。

## 作るときのポイント

- 途中段階からの復帰方法を用意する
- 最終段の後に停止するか循環するか決める
- 各段の出力が重ならないようにする

## 応用

- 順番演出
- 工程制御
- カウンタ
