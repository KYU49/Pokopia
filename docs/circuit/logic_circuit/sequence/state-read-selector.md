# 動作停止読取り選択出力機構

> **対象の動作中／停止中を読み取り、出力先を選ぶ。**

| 項目 | 内容 |
|---|---|
| 分類 | 選択・順序制御 |
| 難易度 | ★★★★☆ |
| 主な用途 | 状態読取り・分岐 |
| 状態保持 | 構成による |
| リセット | 構成による |

## できること

対象が動作中か停止中かを読み取り、その状態に応じて別々の出力へ分岐します。

## 仕組み

動作状態の変化と電源状態の信号条件を利用し、現在状態に対応した経路だけを有効にします。

## 作るときのポイント

- 状態変化の瞬間と現在状態を混同しない
- 読取り対象へ信号を返してしまわないようにする
- 初期状態を明記する

## 応用

- 状態表示
- 自動分岐
- 選択回路
