# 1個だけONできる回路

> **複数候補の中から、常に1か所だけをONにする。**

| 項目 | 内容 |
|---|---|
| 分類 | 選択・順序制御 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 排他的選択 |
| 状態保持 | あり |
| リセット | 構成による |

## できること

複数の出力候補があっても、同時にONになるのは1つだけになるよう制御します。

## 仕組み

新しい選択をONにするとき、以前の選択をOFFにする信号も同時に送ります。

## 作るときのポイント

- 選択なし状態を許可するか決める
- 同時入力時の優先順位を確認する
- 切替途中に複数ONにならないか確認する

## 応用

- メニュー選択
- 行き先選択
- 相互ロック
