# 2進数加算回路

> **各ビットの和と繰り上がりを計算する。**

| 項目 | 内容 |
|---|---|
| 分類 | 演算回路 |
| 難易度 | ★★★★★ |
| 主な用途 | 2進数加算 |
| 状態保持 | あり |
| リセット | 必要 |

## できること

2進数の入力を受け取り、各桁の和と繰り上がりを出力します。

## 仕組み

AND・XOR・保持・繰り上がり処理を組み合わせ、下位桁から上位桁へ計算を伝えます。

## 作るときのポイント

- 入力を保持してから計算を始める
- 繰り上がりの伝達順を確認する
- 計算後に全段をリセットできるようにする

## 応用

- 電卓
- カウンタ
- BCD演算
