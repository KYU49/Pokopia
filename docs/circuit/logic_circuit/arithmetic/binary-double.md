# 2進数2倍回路

> **2進数を1桁ずらして2倍にする。**

| 項目 | 内容 |
|---|---|
| 分類 | 演算回路 |
| 難易度 | ★★★☆☆ |
| 主な用途 | ビットシフト・乗算 |
| 状態保持 | 構成による |
| リセット | 構成による |

## できること

2進数の各桁を1つ上位へ移し、値を2倍として扱います。

## 仕組み

2進数では左へ1ビット移動すると2倍になるため、入力された各ビットを1段上位の出力へ対応させます。
