# BCD補正回路

> **10進1桁として扱えるよう、必要なときに補正する。**

| 項目 | 内容 |
|---|---|
| 分類 | 演算回路 |
| 難易度 | ★★★★★ |
| 主な用途 | 10進表示用の補正 |
| 状態保持 | 構成による |
| リセット | 必要 |

## できること

2進数の加算結果をBCDとして表示するため、10以上になった場合に補正値を加えます。

## 仕組み

BCDでは1桁を0000～1001で扱うため、1010以上になった場合や繰り上がり条件に応じて補正します。

## 作るときのポイント

- 補正条件を明確に分ける
- 加算前と補正後の保持状態を混同しない
- 表示回路のビット順を統一する

## 応用

- 10進電卓
- 桁上がり表示
- 数値カウンタ
