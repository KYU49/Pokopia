# 任意周期出力回路

> **設定した周期で繰り返し信号を出す。**

| 項目 | 内容 |
|---|---|
| 分類 | 信号制御回路 |
| 難易度 | ★★★☆☆ |
| 主な用途 | クロック・周期動作 |
| 状態保持 | 構成による |
| リセット | 停止方法による |

## できること

一定周期で繰り返し信号を出力します。周期動作する設備や複数回路のタイミング合わせに使えます。

## 仕組み

遅延要素と戻り経路を組み合わせ、出力を次の入力として循環させます。

## 作るときのポイント

- 停止方法を先に決める
- 周期が方角依存で変わらないか確認する
- 複数段を組み合わせる場合は誤差を確認する

## 応用

- クロック
- 点滅演出
- 自動設備
