# 1回の入力で一定回数を出力する回路

> **1回の開始入力を、決めた回数の出力へ変換する。**

| 項目 | 内容 |
|---|---|
| 分類 | 信号制御回路 |
| 難易度 | ★★★★☆ |
| 主な用途 | 回数制御 |
| 状態保持 | 構成による |
| リセット | 必要 |

## できること

開始入力を1回受けると、あらかじめ決めた回数だけ信号を出します。

## 仕組み

周期出力とカウント・停止条件を組み合わせ、指定回数に達したところで循環を止めます。

## 作るときのポイント

- 回数を変更しやすい構成にする
- 停止後に次回開始できるようリセットする
- 出力間隔も記録する

## 応用

- 演出回数の指定
- 電卓入力
- 複数回必要な制御
