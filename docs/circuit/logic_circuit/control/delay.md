# 16F遅延回路

> **1回の信号を確実に16F遅らせる。**

| 項目 | 内容 |
|---|---|
| 分類 | 信号制御回路 |
| 難易度 | ★★☆☆☆ |
| 主な用途 | タイミング調整 |
| 状態保持 | なし |
| リセット | 不要 |

## できること

入力信号を16F遅らせて出力します。入力信号も同時に出力側へ送れば、1回目は即時、2回目は16F後という2段出力もできます。

## 仕組み

水流や状態変化の時間差を利用し、入力から出力までに決められた遅れを作ります。

## 作るときのポイント

- 遅延前の信号と遅延後の信号を混同しない
- 連続入力時に信号が重ならないか確認する
- 16F単位で多段化できるか確認する

## 応用

- 動作順序の調整
- クロック位相調整
- 2回入力が必要な部品の制御
