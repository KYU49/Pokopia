# 入力保持回路

> **一度受けた入力を、後から読み出せる状態として残す。**

| 項目 | 内容 |
|---|---|
| 分類 | 信号制御回路 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 入力記憶 |
| 状態保持 | あり |
| リセット | 必要 |

## できること

瞬間的な入力を状態として保持し、後段の処理が始まるまで残します。

## 仕組み

SET・RESETや継続出力の仕組みを利用し、入力の有無を回路状態として保存します。

## 回路例

参考動画・画像は、確認できたものから追加します。

## 作るときのポイント

- 保持状態が見て分かるようにする
- 入力とリセットが競合しないようにする
- 読み出し後に保持を残すか消すか決める

## 応用

- 演算入力の保存
- 選択状態の保持
- 順番制御
