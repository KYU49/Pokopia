# 1回ANDしたら水が途切れない回路

> **条件成立後、元栓を閉じるまで出力状態を維持する。**

| 項目 | 内容 |
|---|---|
| 分類 | 信号制御回路 |
| 難易度 | ★★★☆☆ |
| 主な用途 | 継続出力・入力無視 |
| 状態保持 | あり |
| リセット | 必要 |

## できること

一度AND条件が成立すると、その後は元栓を閉じるまで水が途切れない状態を作ります。派生構成では2回目以降の入力を無視できます。

## 仕組み

AND成立時に継続水路を開き、保持された水流をそのまま出力として利用します。

## 作るときのポイント

- 元栓による確実なリセット経路を用意する
- 保持後の追加入力が出力へ影響しないか確認する
- 水源の状態を初期化できるようにする

## 応用

- ワンショット入力
- 入力保持
- 開始後の連続運転
