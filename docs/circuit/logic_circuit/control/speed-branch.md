# 同じ操作なのに速さで結果が変わる回路

> **入力速度の違いを判定して出力先を変える。**

| 項目 | 内容 |
|---|---|
| 分類 | 信号制御回路 |
| 難易度 | ★★★★☆ |
| 主な用途 | 操作速度の判定 |
| 状態保持 | 構成による |
| リセット | 構成による |

## できること

同じ操作でも、入力する速さや間隔によって異なる結果を出します。

## 仕組み

先に入った信号が一定時間だけ回路状態を変え、その時間内に次の入力が来るかどうかで分岐させます。

## 作るときのポイント

- 入力間隔の許容範囲を確認する
- 遅延時間と操作速度の関係を調整する
- 誤操作時に回路を戻せるようにする

## 応用

- タイミングゲーム
- 操作速度による認証
- 演出分岐
